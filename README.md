# ui-motion — an agent skill for websites that feel commissioned

Drop one folder into your agent's skill directory and it stops producing gradient-purple template pages. It produces sites with a palette that holds, masked type that reveals on a curve, one WebGL signature moment that earns its ~8KB, and a performance budget it has to sign off against.

This repository is **also a plugin**: the root carries `.claude-plugin/` and `.qoder-plugin/` manifests, so Claude Code and Qoder can install it straight from the GitHub link — no cloning, no copying.

```
skills/ui-motion/
  SKILL.md          the operating manual — 14 sections, every rule checkable
  references/       11 deep-dive documents: motion, scroll, WebGL, type, a11y, QA
  assets/           copy-paste CSS / JS / shaders — zero dependencies
  scripts/          audit.mjs (rule gate) and serve.mjs (static server), shipped to the agent
examples/index.html one complete page, assembled and working
bin/ui-skill.mjs    installer for six agent homes
install.sh · install.ps1
```

MIT · no build step · no runtime dependency · Node 18+ only for the installer and the audit.

**Live reference build:** https://whalerr09.github.io/UI-skill/examples/ — the page is generated by the skill's own tokens and motion CSS, and the CI audits it with the skill's own rule gate before deploying.

## Install

### One line, straight from this repo

**Windows PowerShell**

```powershell
irm https://raw.githubusercontent.com/Whalerr09/UI-skill/main/install.ps1 | iex
```

**macOS / Linux / WSL**

```bash
curl -fsSL https://raw.githubusercontent.com/Whalerr09/UI-skill/main/install.sh | bash
```

Each one fetches the repository, runs `bin/ui-skill.mjs`, and installs `skills/ui-motion/` into
`~/.claude/skills/ui-motion` and `~/.qoder/skills/ui-motion`. Without Node they fall back to a plain
folder copy of the same payload.

To force a replace or pick targets without cloning, hand the fetched script its arguments:

```powershell
# Windows
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/Whalerr09/UI-skill/main/install.ps1))) -Force -Target claude
```

```bash
# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/Whalerr09/UI-skill/main/install.sh | bash -s -- --force --target cursor --project
```

### Claude Code — as a plugin

```bash
claude plugin marketplace add Whalerr09/UI-skill
claude plugin install ui-skill@ui-motion
```

Or in a session: `/plugin` → Marketplaces → add `Whalerr09/UI-skill` → install `ui-skill`.
`.claude-plugin/marketplace.json` points its single entry at the repository root, whose default
`skills/` scan picks up `skills/ui-motion/SKILL.md`.

Two things worth knowing:

- **No SSH configured?** `claude plugin marketplace add` clones over git. Set
  `CLAUDE_CODE_PLUGIN_PREFER_HTTPS=1` and it uses HTTPS instead — the usual fix on Windows.
- **Updates.** Background auto-update is off by default. Pull a new version with
  `claude plugin update ui-skill@ui-motion` in the shell, or `/plugin marketplace update ui-motion`
  in a session (or turn on **Enable auto-update** for this marketplace in `/plugin`).

Contributors can check the packaging without leaving the terminal: `claude plugin validate .`.

### Qoder — as a plugin, or as a skill folder

**Plugin.** Add this marketplace JSON to Qoder's plugin marketplace list:

```
https://raw.githubusercontent.com/Whalerr09/UI-skill/main/.qoder-plugin/marketplace.json
```

If the `qodercli` is on your PATH, the same thing from the terminal:

```bash
qodercli plugin validate "$(pwd)"                        # from a clone of this repo
qodercli plugin install --scope local "<path-or-repo>"   # then qodercli skills list
```

**Skill folder** (verified path, works today with nothing installed): run the `curl`/`irm`
one-liner above, or `npx --yes github:Whalerr09/UI-skill install --target qoder`. The folder
lands in `~/.qoder/skills/ui-motion`.

### npm / npx, straight from GitHub

```bash
npx --yes github:Whalerr09/UI-skill install --all
npx --yes github:Whalerr09/UI-skill install --target cursor --project
npx --yes github:Whalerr09/UI-skill doctor
```

No npm publish needed — npm clones the repo for the command.

### From a clone, or by hand

```bash
git clone https://github.com/Whalerr09/UI-skill.git
cd UI-skill
./install.sh          # macOS / Linux
.\install.ps1         # Windows
```

Manual is a folder copy — the payload is self-contained:

| Agent | Destination | Kind |
| --- | --- | --- |
| Claude Code | `~/.claude/skills/ui-motion/` · plugin | folder |
| Qoder | `~/.qoder/skills/ui-motion/` · plugin | folder |
| Cursor | `.cursor/rules/ui-motion.mdc` | one file |
| Windsurf | `.windsurf/rules/ui-motion.md` | one file |
| GitHub Copilot | `.github/instructions/ui-motion.instructions.md` | one file |

Folder and plugin targets get `SKILL.md` + `references/` + `assets/` + `scripts/`. Single-file
targets get a distilled rule set generated from `SKILL.md`, because those agents cannot follow
links into a folder they were never given.

## Installer options

```bash
ui-skill install [options]          # npx --yes github:Whalerr09/UI-skill install …

  -t, --target <name>   claude | qoder | cursor | windsurf | copilot | agents  (repeatable)
      --all             every target
      --project         install into the current repo instead of your home
      --link            symlink the source folder (Windows: junction, falls back to copy)
  -f, --force           replace an existing install
      --dest <path>     custom directory (single target)
      --json            machine-readable result

  uninstall · list · doctor · version
```

PowerShell takes the same switches as `-Target cursor -Project -Force -All -Link -Dest`.

Copy is the default. It needs no admin rights on Windows and keeps working if you move the
repository. Use `--link` while editing the skill itself.

## What it changes

**Before**

> "make me a landing page for my coffee subscription"

A hero, three feature cards, a gradient, `transition: all .3s`, everything fading in at once,
400KB of JavaScript, no reduced-motion path.

**After** — the same prompt, with the skill loaded:

- Palette archetype chosen first (Ink & Bone / Graphite & Paper / Sepia & Ember / Night & Azure /
  Moss & Cream), one accent, six-step neutral ramp.
- Motion level declared (0–3) before any code, then held to it. Level 2 means reveals, masked type,
  hero exit, one pinned section.
- Type scale in `clamp()`, tracking corrected per size, 60–72ch measure.
- Reveals: one `IntersectionObserver`, `rootMargin: 0px 0px -10% 0px`, 35ms grid stagger capped at
  420ms, words at 72ms.
- Hero exit mapped to scroll with `{at, span}` per element and a smoothstep, never a wheel hijack.
- One shader. Paused offscreen, frozen under reduced motion, torn down on `pagehide`.
- The audit run before hand-off — zero errors, budget printed.

## The rules it enforces

```css
--ease-out: cubic-bezier(.16, 1, .3, 1);     /* the signature curve */
--ease:     cubic-bezier(.22, .61, .36, 1);  /* generic UI */
--ease-io:  cubic-bezier(.65, 0, .35, 1);    /* exits */
```

| | |
| --- | --- |
| Entrances | `--ease-out`, 620–900ms, travel 8–40px, scale 0.96 → 1 max |
| Exits | `--ease-io`, 0.6 × the enter duration |
| Stagger | grids 35ms (cap 420ms) · words 72ms · rows 85ms · header→body 120ms |
| Reveals | one observer, fire once, show immediately if already in view |
| Scroll | one passive listener, rAF-coalesced, writes `--scroll-y` / `--scroll-p` |
| Pinning | `position: sticky` at 2.5–4× viewport. Never wheel or touch hijacking |
| WebGL | ≤ 2 contexts, DPR ≤ 2, pause offscreen + hidden tab, one still frame under reduced motion |
| Budget | LCP ≤ 2.0s · CLS ≤ 0.02 · INP ≤ 120ms · JS ≤ 180KB gzip · CSS ≤ 60KB gzip |

`transition: all`, animated layout properties, unbounded `will-change`, missing `:focus-visible`,
`user-scalable=no`, lazy hero images and canvases without `aria-hidden` are defects, not preferences.

## Audit a build

The auditor ships **inside** the skill, so an installed copy can gate the project it is writing:

```bash
node <skill-dir>/scripts/audit.mjs ./dist              # installed copy
node skills/ui-motion/scripts/audit.mjs ./dist         # from a clone of this repo
node skills/ui-motion/scripts/audit.mjs ./dist --strict
node skills/ui-motion/scripts/audit.mjs ./dist --json
```

Static, dependency-free, exit code 1 on errors. It reads HTML, CSS and JS and reports file, line,
rule and the fix:

```
src/app.css
  error  118: Transition on `height` triggers layout every frame.
         rule transition-layout — Switch to transform/opacity, or animate
         `grid-template-rows` for accordions.
```

Rules cover: `transition: all` · layout properties in transitions · `will-change` sprawl · scroll
hijacking · `eval` · `document.write` · rAF inside `setInterval` · console logging in production ·
WebGL context count · observer count · canvas labelling · image dimensions · lazy LCP images ·
viewport zoom lock · `outline: none` · `@import` · z-index sprawl · `100vh` · missing `lang`,
`<title>`, meta description, single `<h1>` · missing reduced-motion block · JS/CSS/image weight.

## Using it

Once installed, the agent picks the skill up when the task matches — a landing page, a marketing
site, a portfolio, a hero animation, a shader background, or "make this look premium".

You can also ask for it directly:

```
Use the ui-motion skill. Build a landing page for a single-origin coffee
subscription. Motion level 2, Sepia & Ember palette, one shader moment in the
hero. Target: LCP under 2s on a mid-range phone.
```

The skill's phase 0 asks for the four decisions that actually determine the result — palette
archetype, type pairing, motion level, signature moment — and then holds them. If you skip them,
it proposes and proceeds.

## Requirements

- Node 18+ for the installer and the audit. The skill itself is Markdown, CSS and ES modules —
  nothing to build.
- The demo and any shader page need to be served over HTTP, not opened from `file://`.
- Three.js is only needed if you use `assets/js/gl/orb.js`.

## Troubleshooting

| Symptom | Cause | Fix |
| --- | --- | --- |
| Agent never uses the skill | Installed to the wrong home, or a `rules` target where the agent expects a folder | `npx --yes github:Whalerr09/UI-skill doctor` — it lists every copy it can find |
| `claude plugin install` finds nothing | Marketplace not added, or added from an older commit | `/plugin marketplace update ui-motion`, then install `ui-skill@ui-motion` |
| `claude plugin marketplace add` asks for a key / fails | No SSH setup for git on that machine | `CLAUDE_CODE_PLUGIN_PREFER_HTTPS=1 claude plugin marketplace add Whalerr09/UI-skill` |
| Demo link 404s | GitHub Pages is not switched to the Actions source yet | Settings → Pages → Source: **GitHub Actions**; then push to main or run the `pages` workflow |
| `install.ps1` blocked by execution policy | PowerShell default on Windows | `powershell -ExecutionPolicy Bypass -File .\install.ps1` |
| Shader page is black | WebGL unavailable, or the canvas is behind an opaque parent | The CSS fallback must already look complete — see `references/04` |
| Reveals never fire | The `.js` class is missing from `<html>` | Add the inline head script: `document.documentElement.classList.add('js')` |
| Layout jumps on mobile | `100vh`, or images without `width`/`height` | `100svh`; intrinsic dimensions — the audit flags both |
| `npx github:` fails | npm cannot clone the repo | Use the one-line installer, or clone and run `install.sh` / `install.ps1` |
| Want it gone | — | `npx --yes github:Whalerr09/UI-skill uninstall --all` |
