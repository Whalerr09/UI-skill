Questions

Before you write

Does this need an animation library?

No. The reveal engine is one IntersectionObserver, the scroll engine is one rAF, and the shader host is dependency-free. A library is only justified when the project already has one.

What happens without WebGL?

The gradient fallback paints first and stays. It is designed to look complete on its own, so a failed context is invisible to the visitor.

And with reduced motion?

Every travel animation becomes an instant state, the shader renders one still frame, parallax and the cursor field never initialise, and the pinned section unpins.

Can I use this with React or Astro?

Yes. The CSS is framework-agnostic. The JS modules are plain ES modules; wrap them in an effect or a client island. See references/09-stack-adapters.md.
